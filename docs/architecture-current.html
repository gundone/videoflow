VideoFlow — Current Architecture

Implemented: AuthService (JWT+JWKS) + UploadService (presigned S3) + React Frontend

Frontend (React SPA)

  • • Vite + TypeScript + react-router-dom
  • • Auth: register / login / JWT storage
  • • Upload: presigned URL → direct S3 PUT
  • • Progress bar via XMLHttpRequest

Backend Services

  • • AuthService: JWT (RSA-256) + refresh token hash + BCrypt
  • • AuthService: dual ORM (EF Core / Dapper), ULID IDs
  • • UploadService: presigned S3 URLs for direct upload
  • • Both protect endpoints via JWT Bearer Auth

Infrastructure

  • • Docker Compose: PostgreSQL, MinIO, Redis, Kafka
  • • MinIO: bucket videos, CORS :5173, HTTP presigned URLs
  • • AuthService publishes JWKS at /.well-known/jwks.json
  • • UploadService validates via JWKS (auto-cached)
