VideoFlow — Full Architecture

Solid = implemented  |  Orange dashed = planned

Presentation

  • • React SPA (Vite + TypeScript) — localhost:5173
  • • Auth: register / login / JWT in localStorage
  • • Upload: file picker + progress bar → direct S3
  • • Future: HLS.js player for video playback

Application Services

  • • AuthService — JWT RS256 + JWKS, BCrypt, refresh rotation
  • • UploadService — presigned S3 URLs, Kafka publisher
  • • VideoService — metadata CRUD via gRPC (planned)
  • • ProcessingService — FFmpeg → HLS via Kafka (planned)
  • • API Gateway — YARP reverse proxy (planned)

Data Infrastructure

  • • PostgreSQL — videoflow_auth (done) + videoflow_videos (planned)
  • • MinIO — videos bucket (done) + hls bucket (planned)
  • • Kafka — single KRaft node (done, integration needed)
  • • Redis — sessions / cache
  • • All services run via Docker Compose
